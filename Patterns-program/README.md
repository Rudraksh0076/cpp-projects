# 🔷 Hollow Diamond Pattern

A C++ program that prints a hollow diamond pattern based on user input. This project helps practice loops, nested loops, 
and pattern programming.

## ✨ Features

- User-defined size
- Hollow diamond pattern
- Console output
- Easy to understand code

## 🛠️ Technologies Used

- C++
- Visual Studio Code
- Git & GitHub

## 📚 Concepts Practiced

- Nested Loops
- Conditional Statements
- Pattern Programming
- User Input
- Console Output

## ▶️ How to Run

1. Clone this repository.
2. Open hollow-diamond.cpp.
3. Compile and run the program.

Example:

bash
g++ hollow-diamond.cpp -o diamond
./diamond
